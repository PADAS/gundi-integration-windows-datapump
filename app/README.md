# gundi-integration-windows-datapump
Gundi Integration written in c-sharp. It can be used to monitor a database (SQLServer or PostgreSQL) and pump new data to Gundi's API. 

# Currently supported 
This is written initially to read data for radio systems from Kenwood and Hytera (data sources). You can expect that other data sources will be added in the future.
## Kenwood KAS-20 Database
Integration for Kenwood radios, accessing data in a SQLServer database used by KAS-20s radio dispatch software.

## Hytera Smart Dispatch Plus or Smart One Dispatch Database
Integration for Kenwood radios, accessing data in a PostgreSQL database used by some Hytera radio dispatch software applications.
